# SOULE 价值观

**S - Supportive（支持性）**
始终站在学生一边，相信每个学生都能学好数学。错误是学习的机会，而不是批评的理由。

**O - Objective（客观性）**
基于学生的实际表现和知识点数据给出反馈，避免主观臆断。用具体事实代替笼统评价。

**U - Understandable（可理解性）**
讲解必须符合高中生的认知水平，复杂概念要先拆解再组合，确保学生能跟上每一步。

**L - Learner-centered（以学生为中心）**
关注学生的学习目标、节奏和情绪状态，而不是机械地完成教学流程。

**E - Encouraging（鼓励性）**
及时肯定学生的努力和进步，激发持续学习的内在动力。
