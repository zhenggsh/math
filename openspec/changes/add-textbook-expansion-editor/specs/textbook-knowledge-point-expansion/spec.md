## ADDED Requirements

### Requirement: 编辑模式入口

在「扩充知识点」弹窗的预览校验步骤中，系统必须提供进入编辑模式的入口，使教师可以在校验失败或需要微调时直接修改上传的框架文件和 Markdown 文件。

#### Scenario: 进入编辑模式
- **WHEN** 教师完成框架文件和内容文件上传并看到预览校验结果
- **THEN** 系统显示「进入编辑模式」按钮
- **AND** 教师点击后左右预览面板切换为可编辑状态

#### Scenario: CSV 文件禁用编辑
- **WHEN** 上传的框架文件是 .csv 格式
- **THEN**「进入编辑模式」按钮禁用
- **AND** 悬停时提示「CSV 编辑本期暂不支持，请在本地修改后重新上传」

#### Scenario: 多工作表 xlsx 警告
- **WHEN** 上传的框架文件是包含多个工作表的 xlsx
- **AND** 教师点击「进入编辑模式」按钮
- **THEN** 系统弹出确认对话框提示「编辑模式会重新生成 xlsx 文件，原合并单元格将被拆分，非第一个工作表的数据将丢失」
- **AND** 教师点击「继续」后进入编辑模式
- **AND** 教师点击「取消」后留在预览模式

### Requirement: 编辑后重新校验

任何编辑操作都会使当前的校验结果失效，教师必须重新校验后才能进入确认步骤。

#### Scenario: 编辑后校验状态失效
- **WHEN** 教师在编辑模式下修改 xlsx 行、删除行、新增行、修改 Markdown 文本或执行批量标题层级替换
- **THEN** 系统清空当前的校验结果
- **AND** 禁用「下一步」和「确认扩充」按钮
- **AND** 显示「重新校验」按钮

#### Scenario: 重新校验
- **WHEN** 教师点击「重新校验」按钮
- **THEN** 系统把当前编辑后的 xlsx 行和 Markdown 内容重新序列化为文件
- **AND** 调用现有 `POST /textbooks/:id/validate` 接口
- **AND** 校验成功后显示新的校验报告并允许进入确认步骤
- **AND** 校验失败时显示新的校验错误并继续停留在编辑模式

### Requirement: 编辑草稿持久化

系统必须支持在浏览器会话中保存和恢复编辑草稿，以便教师误关弹窗后可以不丢失未提交的修改。

#### Scenario: 保存编辑草稿
- **WHEN** 教师关闭弹窗且存在未保存的编辑（xlsx 行或 Markdown 内容与原始解析结果不同）
- **THEN** 系统弹出确认对话框提示「检测到未提交的编辑，是否保存为草稿？」
- **AND** 提供「保存」「不保存」「取消」三个选项
- **AND** 点击「保存」后把编辑后的 xlsx 行、Markdown 内容以及原始文件指纹存入 `sessionStorage`
- **AND** 点击「不保存」后清除草稿并关闭弹窗
- **AND** 点击「取消」后留在弹窗不关闭

#### Scenario: 恢复编辑草稿
- **WHEN** 教师再次打开同一教材的「扩充知识点」弹窗并上传与草稿指纹一致的原始文件
- **THEN** 系统读取 `sessionStorage` 中的草稿并用编辑后的状态初始化编辑器
- **AND** 若原始文件与草稿指纹不一致，系统丢弃编辑状态并按新文件重新初始化

## MODIFIED Requirements

### Requirement: 知识点扩充入口

教材详情页必须提供「扩充知识点」入口，允许教师上传新的 xlsx 和 md 文件。上传后的预览校验步骤还必须提供进入编辑模式的入口。

#### Scenario: 打开扩充弹窗
- **WHEN** 教师在教材详情页点击「扩充知识点」按钮
- **THEN** 系统导航到弹窗并显示上传步骤
- **AND** 弹窗要求上传框架文件（.xlsx）和内容文件（.md）
- **AND** 未选择文件时确认按钮禁用

#### Scenario: 校验后显示编辑入口
- **WHEN** 教师上传框架文件和内容文件并进入预览校验步骤
- **THEN** 系统除了显示校验报告外，还显示「进入编辑模式」按钮
- **AND** 点击该按钮后按照「编辑模式入口」要求处理
