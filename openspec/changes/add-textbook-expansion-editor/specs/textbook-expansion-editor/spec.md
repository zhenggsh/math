## ADDED Requirements

### Requirement: xlsx 框架行编辑

编辑模式必须提供可编辑的 xlsx 框架表格，支持增删改行，并在行级别校验知识点编号。

#### Scenario: 修改现有行
- **WHEN** 教师在编辑表格中点击某单元格
- **THEN** 该单元格变为可输入状态
- **AND** 按 `Enter` 或失去焦点后保存修改
- **AND** 按 `Esc` 取消修改并恢复旧值

#### Scenario: 删除行
- **WHEN** 教师点击某行末尾的「删除」按钮
- **THEN** 系统从表格中移除该行
- **AND** 同步删除 Markdown 中对应的知识点内容块

#### Scenario: 插入行
- **WHEN** 教师点击某行末尾的「上方插入」或「下方插入」按钮
- **THEN** 系统在该位置插入一行
- **AND** 新行所有列初始化为空字符串
- **AND** 新行获得唯一的内部 `rowId`
- **AND** 若新行填写合法的知识点编号，系统在 Markdown 中按父级插入算法创建对应内容块

#### Scenario: 行级知识点编号校验
- **WHEN** 教师编辑一行的知识点编号
- **THEN** 系统即时检查编号是否为空、是否符合 `^\d+(\.\d+)*$` 格式、以及是否在所有行中唯一
- **AND** 校验失败时在该行显示红色错误提示
- **AND** 该校验失败行不触发 Markdown 同步，直到修复

#### Scenario: 列结构保持不变
- **WHEN** 教师编辑表格中的单元格
- **THEN** 系统只允许修改现有列的值
- **AND** 本期不支持新增、删除或重命名列

### Requirement: Markdown 内容编辑

编辑模式必须提供带行号的 Markdown 源文本编辑器，允许教师直接修改内容。

#### Scenario: 直接编辑 Markdown 文本
- **WHEN** 教师进入编辑模式且已上传内容文件
- **THEN** 右侧面板显示带行号的 `<textarea>`
- **AND** 教师输入的修改会实时更新当前 Markdown 内容状态
- **AND** 修改后清空校验结果

#### Scenario: 大文件编辑禁用
- **WHEN** 上传的内容文件大小超过 1 MB
- **THEN** 系统禁用 Markdown 编辑区域
- **AND** 显示提示「文件过大，建议在本地编辑后重新上传」
- **AND** xlsx 框架编辑器仍可使用

#### Scenario: 缺少内容文件
- **WHEN** 教师只上传了框架文件，未上传内容文件
- **THEN** 右侧 Markdown 编辑区域显示「缺少内容文件，无法在线编辑知识点内容」
- **AND** xlsx 框架编辑器仍可使用

### Requirement: Markdown 标题层级批量替换

系统必须支持批量替换 Markdown 中知识点标题的层级，可作用于全部标题或仅选中的知识点编号。

#### Scenario: 批量替换全部标题层级
- **WHEN** 教师在「批量替换标题层级」控件中选择源层级（如 `###`）和目标层级（如 `####`）
- **AND** 选择范围为「全部」
- **THEN** 系统把 Markdown 中所有匹配源层级的知识点标题行替换为目标层级
- **AND** 保留标题行中知识点编号之后的名称和后续内容不变

#### Scenario: 批量替换选中知识点标题层级
- **WHEN** 教师在 xlsx 框架表格中通过行首 checkbox 选中若干行
- **AND** 在「批量替换标题层级」控件中选择源层级和目标层级
- **AND** 选择范围为「仅选中的知识点编号」
- **THEN** 系统只替换这些选中编号对应的知识点标题行
- **AND** 不影响其他标题行

#### Scenario: 选中编号在 Markdown 中不存在
- **WHEN** 教师选择「仅选中的知识点编号」范围
- **AND** 选中的编号在 Markdown 中没有对应标题行
- **THEN** 批量替换操作不修改任何内容
- **AND** 控件旁显示提示「选中的知识点在内容文件中未出现」

#### Scenario: 替换后重新校验
- **WHEN** 教师执行批量标题层级替换后
- **THEN** 系统清空当前校验结果
- **AND** 要求教师点击「重新校验」后才能进入确认步骤

### Requirement: xlsx 到 Markdown 单向同步

xlsx 框架表格的变更必须单向同步到 Markdown 内容块；Markdown 文本编辑不反向同步到 xlsx。

#### Scenario: 修改行同步标题
- **WHEN** 教师修改某行的知识点编号或名称列
- **THEN** 系统找到该行对应 Markdown 内容块
- **AND** 更新内容块的标题行以反映新的编号或名称
- **AND** 保留内容块的正文内容不变

#### Scenario: 删除行同步删除内容块
- **WHEN** 教师删除某行
- **THEN** 系统删除 Markdown 中对应的知识点内容块（包括标题和正文）

#### Scenario: 新增行插入内容块
- **WHEN** 教师新增一行并填写合法的知识点编号
- **THEN** 系统根据编号的父级寻找合适的插入位置
- **AND** 若父级内容块存在，则插入到该父级最后一个后代之后
- **AND** 若父级不存在但祖父级存在，则插入到祖父级最后一个后代之后
- **AND** 若都找不到，则追加到 Markdown 文件末尾
- **AND** 新内容块正文为占位注释 `<!-- 请补充 ${code} 的内容 -->`

#### Scenario: 找不到对应内容块
- **WHEN** 某行的内部 `rowId` 在 Markdown 中找不到对应内容块
- **THEN** 系统在该行显示黄色警告标签「未找到对应内容块，请在右侧手动检查」
- **AND** 跳过该行的同步操作，不修改 Markdown

#### Scenario: 单向同步提示
- **WHEN** 教师进入编辑模式
- **THEN** 编辑区域顶部显示提示「xlsx 变更会单向同步 md 标题，正文修改不会被覆盖」

### Requirement: 编辑状态与校验隔离

编辑状态必须和校验结果隔离：编辑操作会重置校验，校验失败不会自动撤销编辑。

#### Scenario: 编辑后校验结果清空
- **WHEN** 教师对 xlsx 行或 Markdown 内容做任何修改
- **THEN** 系统将 `validationResult` 设为 `null`
- **AND** 禁用「下一步」和「确认扩充」按钮
- **AND** 启用「重新校验」按钮

#### Scenario: 校验失败保留编辑
- **WHEN** 教师点击「重新校验」但后端返回错误
- **THEN** 系统保留当前编辑状态
- **AND** 显示新的校验错误供教师继续修正

### Requirement: 编辑组件异常处理

编辑模式必须处理文件序列化异常、多工作表警告和 CSV 禁用等边界情况。

#### Scenario: xlsx 序列化异常
- **WHEN** 系统调用 `serializeXlsxPreview` 生成文件时抛出异常
- **THEN** 系统在弹窗顶部显示 Alert：「生成框架文件失败，请检查是否包含异常字符或空列。」
- **AND** 不调用校验/确认接口
- **AND** 保持编辑模式可用

#### Scenario: 多工作表 xlsx 进入编辑
- **WHEN** 上传的 xlsx 包含多个工作表
- **AND** 教师点击「进入编辑模式」
- **THEN** 系统弹出确认对话框提示非第一个工作表数据会丢失
- **AND** 教师确认后进入编辑模式，否则留在预览模式

#### Scenario: CSV 禁用编辑
- **WHEN** 上传的框架文件是 .csv
- **THEN**「进入编辑模式」按钮禁用
- **AND** 悬停提示 CSV 不支持在线编辑
