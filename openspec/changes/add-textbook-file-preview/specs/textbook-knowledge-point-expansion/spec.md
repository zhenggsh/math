# Delta Spec: textbook-knowledge-point-expansion (变更)

## MODIFIED Requirements

### Requirement: 教材详情页展示

系统必须提供教材详情页，展示指定教材的元数据和 iksm 文件预览。详情页布局为：教材信息卡片 + 双栏文件预览（左侧框架文件、右侧内容文件），不再展示数据库知识点表格（该信息由文件预览覆盖，数据库视图由学习页承担）。

#### Scenario: 进入教材详情页
- **WHEN** 教师从教材列表点击「详情」按钮
- **THEN** 系统导航到 `/teacher/textbooks/:id`
- **AND** 页面显示教材名称、文件名、框架类型、知识点数量、内容文件状态、最后修改时间
- **AND** 页面以双栏展示该教材 iksm 框架文件（左）和内容文件（右）的预览，支持点击框架行定位内容
- **AND** 页面不再展示数据库知识点表格

#### Scenario: 扩充成功后的高亮位置
- **WHEN** 扩充知识点流程成功完成
- **THEN** 系统在框架文件预览（而非数据库表格）中高亮新增知识点行
- **AND** 文件预览自动刷新为磁盘最新内容

### Requirement: 追加到原 xlsx 文件

系统必须将新知识点行追加到原教材框架文件的框架 sheet 末尾。目标 sheet 必须使用与框架解析器一致的 sheet 检测逻辑确定（选择第一个含合规框架结构的 sheet），不得固定写入第一个 sheet。列映射必须按表头名进行，兼容不同的列顺序（如编号列在最后一列），不得按固定位置写入。

#### Scenario: 成功追加 xlsx
- **WHEN** 扩充成功完成
- **THEN** 原 xlsx 文件的框架 sheet 末尾新增对应知识点行
- **AND** 新行的各列值与该 sheet 表头一一对应（含知识点编号和重要性级别）
- **AND** 原文件中的其他 sheet（如封面）和现有知识点数据保持不变

#### Scenario: 封面在前的多 sheet 文件
- **WHEN** 教材 xlsx 的第一个 sheet 为封面、第二个 sheet 为知识点框架
- **THEN** 新知识点行追加到知识点框架 sheet，封面不被修改

## ADDED Requirements

### Requirement: 扩充弹窗解析与服务端一致

扩充弹窗前端对本地框架文件的预览解析（sheet 选择、表头处理）必须与服务端框架解析器的行为一致：多 sheet 时选择同一检测规则确定的框架 sheet，表头做同样的 trim 处理。两端必须使用共享的测试夹具（封面在前的多 sheet 文件）验证一致性。

#### Scenario: 弹窗预览封面在前的文件
- **WHEN** 教师上传第一个 sheet 为封面的 xlsx 文件
- **THEN** 弹窗预览展示框架 sheet 的行数据，与服务端解析结果一致
