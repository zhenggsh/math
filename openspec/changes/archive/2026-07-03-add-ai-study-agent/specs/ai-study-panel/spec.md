## ADDED Requirements

### Requirement: AI assistant opens from a floating action button
The system SHALL display a floating action button (FAB) on the LearningPage when a knowledge point is selected.

#### Scenario: Student views a knowledge point
- **WHEN** a student is on the LearningPage with a selected knowledge point
- **THEN** a FAB is visible at the bottom-right corner of the screen
- **AND** clicking the FAB opens the AI assistant chat panel

### Requirement: Chat panel opens as a right-side drawer
The system SHALL open the AI assistant as a right-side Drawer with a fixed width of 380px on desktop.

#### Scenario: Student clicks the FAB
- **WHEN** a student clicks the FAB
- **THEN** a Drawer slides in from the right
- **AND** the Drawer width is 380px

### Requirement: Chat panel displays current knowledge point context
The system SHALL display the current knowledge point title at the top of the chat panel.

#### Scenario: Context bar is visible
- **WHEN** the chat panel is open
- **THEN** a context bar at the top shows the current knowledge point title

### Requirement: Chat panel supports user input and message display
The system SHALL provide an input field and a send button for students to ask questions.

#### Scenario: Student types a question
- **WHEN** a student types a question in the input field and clicks send
- **THEN** the user message appears in the chat history
- **AND** the input field is cleared
- **AND** the system sends the message to the backend

#### Scenario: Agent response is displayed
- **WHEN** the backend returns an agent response
- **THEN** the agent message appears in the chat history
- **AND** the loading state is removed

### Requirement: Follow-up chips are displayed after each agent response
The system SHALL render the follow-up questions returned by the backend as clickable chips below the agent message.

#### Scenario: Follow-up chips are shown
- **WHEN** an agent response includes 3 follow-ups
- **THEN** 3 chips are displayed below the agent message
- **AND** each chip shows the follow-up text

#### Scenario: Clicking a follow-up chip starts a new turn
- **WHEN** a student clicks a follow-up chip
- **THEN** the chip text is sent as a new user message
- **AND** the chat history updates accordingly

### Requirement: Chat panel displays suggested starter questions for new sessions
The system SHALL display 3 clickable starter question chips below the welcome message for a new Session with no prior messages. The starter questions are generated by the frontend from the current knowledge point title using a fixed set of templates.

#### Scenario: Student opens panel for a new knowledge point
- **WHEN** a student opens the AI assistant for the first time on a knowledge point
- **THEN** 3 starter question chips are displayed below the welcome message
- **AND** clicking a chip sends its text as a new user message
- **AND** the starter questions are based on the current knowledge point title

### Requirement: Chat panel supports regenerating an agent response
The system SHALL allow a student to regenerate the most recent agent response.

#### Scenario: Student is unhappy with the latest answer
- **WHEN** a student clicks the regenerate button on the latest agent message
- **THEN** the system re-sends the last user message to the backend
- **AND** the existing agent message content is replaced with the new response
- **AND** the follow-up chips are updated

### Requirement: Chat panel provides feedback on agent messages
The system SHALL provide thumbs up and thumbs down buttons on each agent message.

#### Scenario: Student rates an answer
- **WHEN** a student clicks thumbs up or thumbs down on an agent message
- **THEN** the feedback is sent to the backend
- **AND** the button visually reflects the selected feedback
- **AND** the student can change or remove their feedback

### Requirement: Chat panel displays source grounding indicator
The system SHALL display a grounding indicator that the answer is based on the current knowledge point's textbook content.

#### Scenario: Agent answers a question
- **WHEN** an agent message is displayed
- **THEN** a small indicator shows the current knowledge point title as the source
- **AND** the student understands the answer is grounded in the current learning material

### Requirement: Chat panel handles loading and error states
The system SHALL display loading and error states to the student.

#### Scenario: Waiting for agent response
- **WHEN** a message is sent and the backend has not yet responded
- **THEN** the chat shows a loading indicator
- **AND** the send button is disabled

#### Scenario: API returns 503
- **WHEN** the backend returns HTTP 503
- **THEN** the chat displays "AI 助手暂时不可用，请稍后重试"

#### Scenario: API returns 429
- **WHEN** the backend returns HTTP 429
- **THEN** the chat displays "请求太频繁，请稍后再试"
