## ADDED Requirements

### Requirement: The system can compare framework file rows with database knowledge points

The system SHALL expose an endpoint that returns a divergence report comparing the current framework file (xlsx or csv) with the `KnowledgePoint` records stored in the database for the same textbook. The report SHALL identify rows that exist only in the file, rows that exist only in the database, and rows that exist in both but have differing field values.

#### Scenario: Endpoint returns an empty report when file and database match

- **WHEN** a teacher requests the divergence report for a textbook whose framework file rows exactly match the database records
- **THEN** the system returns a report with `diverged: false` and an empty issues list

#### Scenario: Endpoint reports rows missing from the database

- **WHEN** a framework file contains a row with code `1.2.3` and the database has no knowledge point with that code
- **THEN** the report contains an issue of type `missing-in-db` for code `1.2.3` with the file row values

#### Scenario: Endpoint reports rows missing from the file

- **WHEN** the database contains a knowledge point with code `1.2.3` and the framework file has no row with that code
- **THEN** the report contains an issue of type `missing-in-file` for code `1.2.3` with the database values

#### Scenario: Endpoint reports rows with changed field values

- **WHEN** both the framework file and the database contain code `1.2.3` but the `name`, `definition`, `characteristics`, `importanceLevel`, `level1`, `level2`, or `level3` values differ
- **THEN** the report contains an issue of type `changed` for code `1.2.3` listing each differing field with the file value and database value

### Requirement: Only authorized users can request a divergence report

The system SHALL allow only users with the TEACHER or ADMIN role to request the divergence report for a textbook. Students SHALL receive a 403 Forbidden response.

#### Scenario: Teacher requests divergence report

- **WHEN** a teacher requests the divergence report for a textbook
- **THEN** the system returns the report

#### Scenario: Student requests divergence report

- **WHEN** a student requests the divergence report for a textbook
- **THEN** the system returns 403 Forbidden

### Requirement: Parser-generated hierarchy rows are excluded from explicit comparison

The system SHALL compare only explicit framework file rows. Rows that are automatically generated by the parser to represent parent hierarchy levels (e.g., a `1.1` row inferred from `1.1.1`) SHALL NOT be reported as missing in the database.

#### Scenario: Parent nodes are not flagged as missing

- **WHEN** the framework file contains only leaf rows such as `1.1.1` and `1.1.2`, and the parser generates implicit `1.1` parent rows
- **THEN** the report does NOT contain a `missing-in-db` issue for code `1.1`
