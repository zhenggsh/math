Layout Clarification

Balanced Layout: Children are distributed horizontally, not diagonally.

  • Root node is centered
  • Left half of children extend horizontally left from root's left edge
  • Right half of children extend horizontally right from root's right edge
  • Each child's own children continue in the same direction (left or right)

Features

  • Layout Switcher: Tree ↔ Balanced dropdown in toolbar
  • MiniMap: Collapsible panel (default: bottom-right), 200×150px
  • Pan: Middle-mouse button drag
  • Zoom: Mouse wheel (future) / toolbar buttons
